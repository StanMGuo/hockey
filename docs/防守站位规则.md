# Hockey Defence Trainer 防守站位规则

这份说明对应 `Game files/index.html` 里的规则引擎（约第 423–585 行）。正确位置不是写死在每道题里的，而是每次根据「谁控球、球在哪、对方有没有人偷跑」算出来。

坐标单位是英尺。

## 1. 坐标

冰场以我们的蓝线为基准：

- \(x\)：从我们的蓝线指向对方球门。\(x = 0\) 是蓝线，\(x = 64\) 是对方球门线，\(x = 75\) 是底线挡板。\(x\) 为负数表示球已经回到中区，更靠近我们自己的球门。
- \(y\)：横向。大约 \(-42.5\) 到 \(+42.5\) 是两侧板墙。
- 横屏时，我们的球门在左边，对方球门在右边。竖屏时，我们的球门在下面，对方球门在上面。

记球的位置为 \((p_x, p_y)\)。球所在的一侧板墙用 \(s\) 表示：

\[
s =
\begin{cases}
\text{题目里写死的 side} & \text{如果这道题指定了 side}\\
+1 & p_y \ge 0\\
-1 & p_y < 0
\end{cases}
\]

\(s = +1\) 和 \(s = -1\) 只是左右互换，规则相同。

两名后卫记为 \(D_1\)、\(D_2\)。程序不规定谁必须去球侧：谁站得更适合球侧任务，谁就是球侧后卫。

## 2. 先判断是哪种局面

控球权优先于球的位置。对方控球时，再按球的深度分类：

\[
\text{kind}=
\begin{cases}
\text{own} & \text{我们控球}\\
\text{rim} & \text{对方准备沿板墙把球打出来}\\
\text{deep} & \text{对方控球，且 } p_x > 45\\
\text{carry} & \text{对方控球，且 } p_x > 8\\
\text{out} & \text{对方控球，且球已经离开进攻区}
\end{cases}
\]

五种局面的意思：

| 种类 | 发生了什么 | 两名后卫要做的事 |
|---|---|---|
| own | 我们拿着球 | 一人守球侧板墙，防止球被清出区；一人补到中路 |
| deep | 对方把球控在很深的位置 | 不追进底角。一人守住蓝线板墙，一人退回中路 |
| rim | 对方想贴着板墙把球传出区 | 球侧后卫几乎贴住板墙把球挡住，另一人退回中路 |
| carry | 对方正沿板墙把球带出来 | 球侧后卫挡在球和蓝线之间，另一人退回去保护中路 |
| out | 球已经出了进攻区 | 两人都往自己球门方向退，并留在球和球门之间 |

## 3. 两个目标区域

每种局面给出两个椭圆。\(S\) 是球侧后卫该站的区域，\(W\) 是另一名后卫该站的区域。椭圆写成 \((c_x,\ c_y,\ r_x,\ r_y)\)：中心和两个方向上的半径。

我们控球时，球越深，两人可以稍微往前站一点。深度系数是：

\[
\delta = \mathrm{clamp}\!\left(\frac{p_x - 20}{45},\ 0,\ 1\right)
\]

\(\mathrm{clamp}(v, a, b)\) 表示把 \(v\) 限制在 \(a\) 和 \(b\) 之间。

| 局面 | 球侧 \(S\) | 另一侧 \(W\) |
|---|---|---|
| own | \((6 + 4\delta,\ 31s,\ 7,\ 9)\) | \((12 + 5\delta,\ -4s,\ 9,\ 11)\) |
| deep | \((9,\ 32s,\ 7,\ 8)\) | \((-1,\ -3s,\ 7,\ 12)\) |
| rim | \((9,\ 35s,\ 7,\ 7)\) | \((-1,\ -3s,\ 7,\ 12)\) |
| carry | \(\big(\mathrm{clamp}(p_x-13,\ 1,\ 26),\ s\cdot\mathrm{clamp}(\|p_y\|-6,\ 18,\ 32),\ 7,\ 8\big)\) | \((-6,\ -4s,\ 7,\ 12)\) |
| out | \(\big(\mathrm{clamp}(p_x-10,\ -20,\ -8),\ s\cdot\mathrm{clamp}(\|p_y\|-10,\ 8,\ 24),\ 5.5,\ 8\big)\) | \((-19.5,\ -3s,\ 5,\ 11)\) |

读这张表时可以记住三个方向：

- \(c_x\) 越小，越靠近我们自己的球门。
- \(c_y\) 的正负跟着 \(s\)。球侧后卫的 \(c_y\) 和 \(s\) 同号，所以站在球那一侧；另一名后卫的 \(c_y\) 和 \(s\) 反号或接近 0，所以站在中路、略偏另一侧。
- \(r_x\)、\(r_y\) 是允许偏差。人站在椭圆里面就算站对。

## 4. 有人偷跑时，中路那个人要改位置

对方球员里，除了当前拿球的人，如果有人满足下面两条，就算偷跑：

- 人在中路或球的另一侧：\(o_y \cdot s < 4\)
- 人已经跑到比较靠后的位置：我们控球时 \(o_x < 14\)，其余局面 \(o_x < 24\)

如果同时有好几个人满足，取 \(o_x\) 最小、也就是最靠近我们球门的那个人，记为 \((L_x, L_y)\)。只修改 \(W\)：

\[
\begin{aligned}
\text{own：}&\quad W_x = \min(W_x,\ L_x + 3)\\
\text{其余：}&\quad W_x = \min(W_x,\ L_x - 6),\quad W_y = W_y + 0.4\,(L_y - W_y)
\end{aligned}
\]

我们控球时，中路后卫不能站到偷跑者身后。对方控球时，中路后卫要留在偷跑者和我们球门之间，并往这个人的横向位置靠一点。

## 5. 怎么打分

球员 \(p\) 到椭圆 \(z\) 的距离是：

\[
d(p, z) = \sqrt{
\left(\frac{p_x - c_x}{r_x}\right)^2 +
\left(\frac{p_y - c_y}{r_y}\right)^2
}
\]

\(d \le 1\) 表示人在椭圆内部。

先给两种角色分配算总成本，选更小的那种。D1 和 D2 对调也算对：

\[
\begin{aligned}
A &= d(D_1, S) + d(D_2, W)\\
B &= d(D_2, S) + d(D_1, W)
\end{aligned}
\]

\(A \le B\) 时，D1 算球侧、D2 算另一侧；否则反过来。每个人再用自己那个椭圆的距离分级：

\[
\text{等级}=
\begin{cases}
\text{good} & d \le 1\\
\text{close} & 1 < d \le 1.8\\
\text{off} & d > 1.8
\end{cases}
\]

界面上的颜色：

| 等级 | 画面 | 含义 |
|---|---|---|
| good | 绿色 | 站在正确区域里 |
| close | 黄色，提示 ALMOST | 接近正确区域 |
| off | 也显示成黄色，提示 TRY AGAIN | 离正确区域较远 |
| danger | 红色 | 触发了下面的危险条件 |

两个人都是绿色，这道题才算完美通过。Test Me 里，如果第一次检查时两人都是 good 或 close，也会给解锁进度加一分；off 和 danger 不加。

## 6. 会直接判成危险的情况

下面的检查只作用于还没达到 good 的人。已经站在绿色区域里的人不会被改成红色。

对方控球，而且这名后卫比球更深入对方区：

\[
p_x > p_x^{\text{球}} + 3
\]

这表示追过了球，判为 danger。

对方控球，而这名后卫被分到中路职责，位置却太深：

\[
\text{角色}=W \quad\text{且}\quad p_x > 20
\]

我们控球，中路那名后卫冲得太深，断球后没有人留在后面：

\[
\text{角色}=W \quad\text{且}\quad p_x > 40
\]

球还在进攻区时（kind 不是 out），至少要有一名后卫守住球侧板墙通道。通道条件是：

\[
p_y \cdot s > \min(18,\ |S_y| - S_{ry})
\quad\text{且}\quad
-6 < p_x <
\begin{cases}
p_x^{\text{球}} & \text{carry}\\
26 & \text{其余局面}
\end{cases}
\]

没有人满足，而且球侧后卫还不是绿色，球侧后卫判为「没守住板墙」。

对方控球时，至少要有一名后卫留在中路、并且比球更靠近我们的球门：

\[
|p_y| < 24 \quad\text{且}\quad p_x < \min(p_x^{\text{球}},\ 12)
\]

没有人满足，而且中路后卫还不是绿色，中路后卫判为「中路空了」。

另外还有只影响总评文字、不单独把某一个人改成红色的情况：

- 两人都在同一侧：两人的 \(y \cdot s\) 都大于 12，或都小于 \(-12\)。
- 两人贴得太近：两人距离小于 10 英尺，并且没有算成同一侧。
- 对方控球时两人都太深：两人的 \(x\) 都大于 22。
